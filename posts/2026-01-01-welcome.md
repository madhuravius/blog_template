This is an example post. Clone the template, delete this post, and write your
own in `posts/` — each Markdown file becomes a clean URL, an RSS feed entry,
and a responsive page.

## What you get

Drop a photo in the shared `posts/images/` folder and reference it by name:

![Build pipeline demo](shared-demo.png "The image pipeline at work")

The build converts it to WebP at a few widths and adds `srcset`/`sizes` so
browsers load the smallest version that fits. Post images get lazy-loaded and
use descriptive alt text, since it came from the Markdown alt attribute.

## Markdown that just works

Tables, strikethrough, and inline code are all supported:

| Feature      | Support |
| ------------ | ------- |
| Fenced code  | Yes     |
| Syntax highlight | Yes |
| Tables       | Yes     |
| ~~Strikethrough~~ | Yes |

And fenced code blocks are highlighted by Pygments:

```python
def cost_per_page(total_cents: float, pages: int) -> float:
    return total_cents / pages
```

```rust
fn cost_per_page(total_cents: f64, pages: usize) -> f64 {
    total_cents / pages as f64
}
```

Edit `posts/`, run `just build`, and you're done.
